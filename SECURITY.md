# Security Policy

If you discover a security vulnerability in this repository (https://github.com/arn-c0de/GDEF-Connect-Spoofer/), please report it privately to the maintainers so we can address it promptly.

Reporting
- Preferred method: Open a private security issue on GitHub or contact the repository owner via their GitHub profile: https://github.com/arn-c0de
- Alternatively, email: arn-c0de@protonmail.com
- If you cannot open a private issue, open a public issue and mark it "security" and request that it be handled privately.

What to include
- A clear description of the issue and the potential impact
- Steps to reproduce and a proof-of-concept when possible
- Affected versions and environment information

Response
- We will acknowledge receipt within 72 hours and provide status updates.
- We will work to provide a fix or mitigation and coordinate disclosure.

Disclosure
- Please do not publicly disclose vulnerabilities until they are fixed and disclosure has been coordinated with the maintainers.
- If you need to send sensitive information, request the maintainer's preferred secure channel or PGP key via their GitHub profile.

Thank you for helping keep this project secure.
